Guia de configuração

Como pegar cada chave e onde colar no app, no seu ritmo e sozinha(o). Leva uns 20 minutos para configurar tudo, e você pode parar e voltar quando quiser. Suas chaves ficam guardadas só no seu computador.

Como abrir as configurações

No app, clique em Configurações (canto inferior esquerdo). Cada integração é um cartão com campos para colar a chave, o botão Salvar e testar (mostra na hora se funcionou) e o link Como pegar, que abre este guia no passo certo.

1. Reportei Essencial

O Reportei é de onde vêm a lista de clientes, as contas de anúncio e os dados do LinkedIn.

  1. Entre em app.reportei.com com o seu usuário.
  2. Abra as configurações da empresa (menu da conta, canto superior) e procure a opção API (pode aparecer como "API Reportei" ou "Integrações → API").
  3. Gere ou copie o token (é um texto longo).
Onde colar: app → Configurações → cartão Reportei → Token da API → Salvar e testar. Deve aparecer "Conectado ao Reportei: N clientes visíveis".
Se você não vê a opção de API, quem administra a conta da Raizhe no Reportei precisa liberar ou gerar o token para você.

2. Trello Essencial

Dá acesso ao board de cada cliente. Esta chave é pessoal: cada pessoa gera a sua.

  1. Entre no Trello com o seu usuário e abra trello.com/app-key.
  2. Copie a API Key (a primeira informação da página).
  3. Na mesma página, clique no link "Token" (ou "gerar um Token manualmente"), depois em Permitir, e copie o Token que aparece.
Onde colar: app → Configurações → cartão Trello → API Key e Token → Salvar e testar. Deve aparecer "Conectado ao Trello como (seu nome)".
Se o Trello pedir para criar um Power-Up antes de mostrar a chave: acesse trello.com/power-ups/admin → Novo → dê um nome (ex.: "Central de Campanhas"), escolha a sua área de trabalho e um e-mail → abra a aba Chave de API → Gerar nova chave de API. A chave e o link do token aparecem ali.

3. Gemini (IA) Recomendado

É a IA que lê as reuniões e o histórico do cliente e monta o "O que estamos atacando", com a linha do tempo de cada frente. O uso normal é gratuito.

  1. Abra aistudio.google.com/apikey e entre com a sua conta Google.
  2. Clique em Criar chave de API (se pedir, escolha ou crie um projeto) e copie a chave.
Onde colar: app → Configurações → cartão Gemini (IA) → Chave da API → Salvar e testar.

4. Meta Ads Essencial

Traz campanhas, conjuntos, criativos e vídeos direto do Meta. O token é pessoal.

Antes: ter acesso ao app do Meta

A Erik faz No app do Meta "Assistente de Campanhas" (developers.facebook.com → o app → Funções do app), a Erik adiciona o seu Facebook como Desenvolvedor ou Testador. Você recebe um convite no Facebook e precisa aceitar. Sem isso o Meta recusa o token.

Gerar o token

  1. Abra o Explorador da Graph API (developers.facebook.com → Ferramentas → Explorador da Graph API).
  2. No campo Aplicativo da Meta (à direita), escolha Assistente de Campanhas.
  3. Em Usuário ou Página, deixe Token de acesso do usuário.
  4. Em Permissões, adicione: ads_read, ads_management, business_management, pages_read_engagement e pages_show_list.
  5. Clique em Gerar token de acesso, autorize e, quando perguntar, selecione todas as contas de anúncio e Páginas dos clientes. Copie o token.

Estender para 60 dias

O token do Explorador dura só algumas horas. Para ele durar 60 dias você precisa do App ID e do App Secret do app (a Erik passa no arquivo de chaves; o App ID já vem preenchido).

Onde colar: app → Configurações → cartão Meta Ads → Token de acesso (o que você copiou), App ID e App Secret → Salvar e testar → depois Estender para 60 dias. O teste mostra a validade e as permissões que faltarem.
Renovação: a cada ~50 dias repita só o "Gerar o token" e clique em Estender. Faltando 7 dias para vencer, aparece um aviso amarelo na barra lateral do app.

5. Google (Ads e planilhas) Essencial

Um único login libera o Google Ads e a leitura das planilhas de leads (inclusive as cores: verde = MQL, vermelho = fora do perfil).

O que vem da Erik (da empresa)

  • Developer Token do Google Ads (fica na conta MCC da Raizhe: Google Ads → Ferramentas → Configuração → Central de API).
  • Client ID e Client Secret do projeto Google da Raizhe.
  • ID da MCC (só números, o código que aparece no topo da conta MCC, sem os traços).

Tudo isso vem no arquivo de chaves da equipe. Se preferir preencher à mão, cole nos campos do cartão.

Conectar a sua conta

  1. No app: Configurações → cartão Google (Ads e planilhas) → confira os 4 campos → clique em Conectar com Google.
  2. O navegador abre. Escolha a conta Google que tem acesso à MCC da Raizhe e às planilhas dos clientes.
  3. Pode aparecer "O Google não verificou este app". É normal: clique em Avançado → Acessar Central de Campanhas (não seguro).
  4. Marque as duas permissões (Google Ads e ver planilhas) e continue. A página mostra "Conectado". Volte ao app e clique em Testar: deve aparecer "Google Ads conectado: N conta(s)".
"Acesso bloqueado" ou "app em teste"? Fale com a Erik: ela precisa adicionar o seu e-mail como usuário de teste (Google Cloud → APIs e serviços → Tela de consentimento OAuth → Usuários de teste).
Planilhas: a sua conta Google precisa ter acesso à planilha do cliente (ou a planilha estar compartilhada por link). Se o app avisar "ative a API do Google Sheets", é um clique da Erik no projeto do Google: console.cloud.google.com → Biblioteca → Google Sheets API → Ativar.

6. LinkedIn Opcional

Não precisa configurar: as campanhas e métricas do LinkedIn já chegam pelo Reportei. A conexão própria só serve para ver o texto dos anúncios e exige o produto "Advertising API" aprovado no LinkedIn. Se for o seu caso, fale com a Erik.

Montar sua lista de clientes

Com Reportei e Trello conectados, o resto é rápido. Você só vê os clientes que adicionar.

  1. App → Configurações → seção Clientes.
  2. Clique em Adicionar do Trello e escolha o board do cliente. O app procura sozinho o projeto do Reportei de mesmo nome e puxa as contas de Meta, Google e LinkedIn que estão ligadas lá.
  3. Se o nome do board for diferente do projeto do Reportei, clique em Vincular projeto na linha do cliente e escolha o certo. Dá para corrigir os IDs das contas na própria linha.
  4. Repita para cada cliente. Clientes que você não atende mais podem ser desmarcados em Ativo.
As planilhas de leads e o "feito na semana" vêm do board do Trello: o app lê os cards da lista "Links Úteis" (qualquer link de planilha do Google) e a lista "O que foi feito na semana".

Cofre P.O. Opcional

Só para quem usa a rotina P.O. no Obsidian. Em Configurações → Cofre Clientes P.O. escolha a pasta do cofre. Com ela, aparecem o "O que estamos atacando" (leitura de reuniões e histórico) e a lista de clientes sai do cofre. Sem o cofre, o app funciona normalmente com campanhas, criativos, "feito na semana" e leads.

Atualizações automáticas

Toda vez que você abre o app, ele confere se há versão nova. Se houver, aparece "Atualizando…" por alguns segundos e ele reinicia sozinho. Você não precisa baixar nada.

  • Para forçar: Configurações → Verificar atualização.
  • Se uma atualização der problema: Configurações → Voltar à versão anterior.
  • Suas chaves e clientes não são apagados nas atualizações.
